## Project Highlights

### ServiceNow MCP for TPRM (AI)
Agentic AI system connecting LLMs to ServiceNow's TPRM module via the Model Context Protocol. Enables natural language querying of vendor questionnaires, risk records, and due diligence requests. Built with LangChain, LangGraph, OpenAI, ChromaDB, HuggingFace, and FastAPI.

### Next Experience UI Themes
Custom ServiceNow workspace themes (Crimson Cream, Rosemerry & Olive) designed for accessibility and corporate branding.

### Vendor Management Workspace
Stepper counter for engagement flow stages in a custom Vendor Management Workspace, built with UI Builder and client-side scripting.
